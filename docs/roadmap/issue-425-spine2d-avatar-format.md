# Issue 425: Evaluate Spine2D Avatar Format

## Goal

Decide whether Spine2D is worth adding as a third avatar format alongside
Live2D and VRM.

## Why

Inspired by AIRI v0.11.0's Spine2D support. See
`docs/roadmap/oss-inspiration-survey-2026-08.md`. Flagged low-priority:
Spine2D's anime-avatar model ecosystem is much smaller than Live2D's, so
this is a real cost (a third rendering pipeline) for a narrow payoff.

## Proposed Scope

- No build yet -- this is an evaluate-on-demand item.
- Revisit only if a specific user has a Spine2D model they want to use.

## Acceptance Criteria

- A documented decision (build / don't build / revisit later) exists,
  same as other scoped-not-implemented items in this directory.
